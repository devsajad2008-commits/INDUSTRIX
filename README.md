# FARAZ INDUSTRIES

FARAZ INDUSTRIES نام این قالب شرکتی صنعتی فارسی و راست‌چین و هویت بصری نمونه‌کار است، نه نام یک شرکت یا محصول واقعی. متن‌ها، نام مجموعه، راه‌های تماس و شبکه‌های اجتماعی برای نمایش هستند و پیش از استفاده‌ی واقعی باید با اطلاعات کسب‌وکار جایگزین شوند.

## اجرا

```bash
npm install
npm run dev
```

صفحات در مسیرهای `/`، `/about`، `/services` و `/contact` در دسترس هستند.

## بررسی و ساخت

```bash
npm run lint
npm run build
npm run start
```

فرم تماس فقط رابط کاربری است و اطلاعاتی ارسال نمی‌کند. اطلاعات تماس و شبکه‌های اجتماعی نمونه‌اند. تصاویر صفحات در `public/images/pages` قرار دارند و نسخه‌های WebP در سایت استفاده می‌شوند. تصاویر پیش‌نمایش شبکه‌های اجتماعی با قرارداد `opengraph-image.jpg` در مسیر هر صفحه نگهداری می‌شوند.

برای تولید آدرس درست تصاویر شبکه‌های اجتماعی، متغیر محیطی `SITE_URL` را با آدرس اصلی سایت (برای نمونه `https://example.com`) تنظیم کنید. در حالت توسعه، مقدار پیش‌فرض `http://localhost:3000` است. آیکون‌ها با Lucide و فونت متغیر Vazirmatn به‌صورت محلی بارگذاری می‌شوند.
